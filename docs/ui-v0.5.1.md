# v0.5.1 · 输入框与权限体验

2026-10-15。移除“工具详情”按钮和整个右侧检查面板；工具参数、输出、diff、命令日志仍保留在对话的每个步骤内，可点击工具行展开。完整事件仍持久化并可导出。

输入区合并为圆角容器，左下角为权限选择，右下角为当前模型名称和发送/停止按钮。点击模型名称可打开设置；离线模式显示“离线演示”。Enter 或 Ctrl+Enter 发送，Shift+Enter 换行；不发送空白输入、不响应长按回车的重复事件。中文输入法预编辑期间的回车不会发送。

| 权限档位 | MiniCodex 行为 |
|---|---|
| 只读 | 仅注册读取与 Git 查看工具，不开放补丁/命令 |
| 默认权限 | 开放补丁和 Windows 原生命令，每次审批 |
| 完全访问 | 开放补丁和 Windows 原生命令，自动执行，事件记录自动批准 |

三档名称采用常见客户端表达，本项目的默认权限仍逐次审批；没有实现 OS 沙箱。完全访问下原生命令具有当前 Windows 用户权限；读写工具仍受原有路径、快照、大小和预算检查。自动执行不绕过取消、源文件一致性检查、进程清理及持久化门禁。Docker 实机功能继续暂缓，不在新的三档下拉框展示；旧配置的 Docker/仅修改模式仍可由引擎加载，手动选择档位后切换到上述模式。

权限变更通过重建下一轮 Runtime 的工具集合和审批策略生效，复用当前 Provider 和 ThreadState。会话 ID、名称、完整消息、历史步骤和输入草稿不改变；下一轮继续此前上下文。运行中禁用权限/模型控件，不能改变正在执行轮次的授权。普通设置和审批策略由 M4 配置层保存；保存失败恢复原档位和运行配置。权限与预算修改沿用当前对话；更改服务地址、模型、Key、流式或连接超时参数时沿用原有新建会话策略。

190 项测试通过，新增 8 项针对以上交互和权限执行的回归；Ruff 检查和格式覆盖 82 个 Python 文件，mypy strict 覆盖 53 个源文件。权限测试在独立临时项目里实际修改文件、执行 Python 验证，并分别检查只读拒绝、默认权限审批、完全访问自动执行、取消与工作区路径边界；未使用外部 API Key。输入法测试使用 Qt 预编辑事件，仍需用户在实际中文输入法中体验确认。

交付 `dist/0.5.1/MiniCodex/MiniCodex.exe` 和 `dist/0.5.1/MiniCodex-0.5.1-Setup.exe`；证据见 `artifacts/ui-0.5.1-validation.json` 和程序包自检记录。M4 的干净 Windows VM、真实多显示器、代码签名等待办边界不变。

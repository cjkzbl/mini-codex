# 执行与本地存储边界

默认只读，模型只能使用当前模式注册的工具。读写受 JSON Schema、工作区边界和审批控制；仓库/工具内容不提升为系统指令。

路径相对工作区，拒绝绝对/UNC/ADS/../敏感目录/.env*/私钥/symlink/junction/reparse point。写入额外拒绝设备名、末尾点/空格、硬链接；父目录须存在。Windows 验证实际句柄；补丁持有父目录及文件锁，批准后再次核对原文。异常/取消尝试回滚，不明结果明确报错；不是跨文件崩溃原子事务。

默认权限的审批只针对本次参数和内容摘要，绑定 approval_id/call_id/turn_id，120 秒失效、回应单次消费。取消、变化、不同任务不能沿用批准。拒绝的相同动作本轮不再请求。v0.5.1 支持用户选择完全访问，此时补丁/原生命令自动执行并记录自动批准；仍校验工作区、源内容、预算和取消。只读模式不注册写入/命令工具。权限变更仅在空闲时生效，不自动重放旧动作。

原生执行须显式选择、仅用于明确可信的项目。exe+argv 不隐式走 shell；.bat/.cmd 拒绝直接执行，脚本需明确解释器和完整参数审批。继承句柄和环境为白名单，不传 API Key、凭据、Python 注入变量。暂停创建、先加入 Job、再启动；停止/超时/正常退出清理 Job 内后代并确认。Job 不是 OS 沙箱，项目脚本可能访问其他宿主文件、网络，或调用 Job 外系统服务。

审批后的源快照核对不是恶意高权限进程的完整隔离。运行中脚本仍可修改宿主文件；程序异常/断电不由应用保证事务性。

Docker 代码已实现、实机验收暂缓：Linux 后端、本地固定镜像 ID，不拉取/降级宿主，挂载过滤临时副本、不写回源项目，非 root、禁网络、只读根、最小权限与 CPU/内存/PID 限制。清理唯一名称容器及匿名卷，只有明确“对象不存在”才确认；连接失败不能视为已清理。

日志/diff/事件/回执使用纯文本；已知 API Key 和常见 sk- 形式脱敏，不等于扫描所有秘密。远程 TLS 验证、不重定向、不继承代理。Key 默认仅在内存、不进设置 repr/项目文件；M4 可显式勾选保存到当前用户的 Windows 凭据管理器，没有明文回退。

测试只使用自身临时项目；10 个脚本化 bug 不调用付费模型。M2 CLI 自检仅对临时项目固定动作自动批准，普通聊天没有自动批准。

M3 在 LocalAppData/MiniCodex 保存 SQLite 会话、展示事件和脱敏工具归档；这包含本机对话及项目内容，不是加密存储。JSONL 默认只有事件元数据；正文仅在应用接口显式指定 include_content=True 时导出；桌面 Ctrl+Shift+E 只导出元数据。已知密钥及常见 sk- 形式脱敏覆盖常见 JSON 转义，不保证识别所有业务秘密。M4 普通设置写入 settings.json，Key 只以服务/数据目录隔离的 Windows 凭据引用关联；重置设置不删除会话。Windows 凭据不能防护同一用户的所有程序。

SQLite 写入失败会终止后续工具执行；JSONL 写入失败提示但保留 SQLite 恢复能力。异常退出后的工具结果记为未知，不自动重放、不恢复批准。上下文摘要和 AGENTS.md 作为参考数据，不能改变注册工具或审批约束；按 Workspace 规则加载且有大小限制。归档回读按当前会话隔离，校验 SHA-256 与文件句柄路径。

启动失败可写 LocalAppData/MiniCodex/startup-error.log。M4 提供当前用户安装器，未做代码签名；默认卸载保留用户数据和凭据。显式清理验证默认路径、应用标记和链接，检查互斥对象及数据锁后删除所属凭据、将目录移至回收站；自定义数据目录始终保留。凭据删除不可回收，失败可能已删部分凭据。静默卸载保留所有数据。干净系统和多屏实机验收仍需执行，见 M4 状态文档。

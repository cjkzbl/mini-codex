# MiniCodex v0.5.5

发布日期：2026-10-15（Asia/Shanghai）。本版为 Docker 沙箱补齐 GUI 入口，并将执行环境与审批权限分开。

- 模型设置新增“执行环境”：Windows 原生执行 / Docker 沙箱；Docker 镜像字段仅在选择 Docker 时启用。
- 输入框的只读 / 默认权限 / 完全访问独立控制审批；切换权限保留当前环境，不再把 Docker 覆盖为 native。
- 只读期间仍记住执行环境；重启后切回默认或完全访问会继续使用保存的环境。选择环境不会自行提高权限。
- 旧配置可继续加载；取消设置或保存失败时保留原配置、会话与草稿。
- 修正“Docker 功能暂缓”的过期提示，补齐 GUI 和真实 Docker 端到端验证。

使用：打开模型设置，选择执行环境并保存；再在输入框左下角选择所需审批权限。Docker 需已启动的 Linux 后端及本地镜像；客户端不自动拉取镜像。Docker 命令操作临时副本，命令改动不写回；文件补丁仍按权限修改原项目。

下载 `MiniCodex-0.5.5-Setup.exe` 安装，或解压 `MiniCodex-0.5.5-Windows-x64.zip` 后运行 MiniCodex.exe；便携包需保留整个目录及 `_internal`。升级前关闭客户端，已有用户数据沿用。SHA-256 校验值见随附的 SHA256SUMS.txt。

验收包含三档权限与两种执行环境的交叉切换、只读状态重启、保存失败回滚、配置兼容、真实 Docker GUI 审批与自动执行，以及既有全部回归。程序尚未代码签名，干净 Windows VM 与所有历史版本升级组合未单独验收。

本机全量 280 项测试通过，包含 16 项真实 Docker 测试；Ruff 与格式检查覆盖 92 个 Python 文件，mypy strict 覆盖 57 个源文件。常规 CI 不要求 Docker，运行 264 项并跳过 16 项实机组。

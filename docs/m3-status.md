# M3 · 会话与上下文可靠性

版本 v0.4.0，日期 2026-10-15。完成计划 Task-020、Task-021、Task-022，沿用 M2 的 Windows 原生执行能力；Docker 实机功能继续按用户选择暂缓。

## 已实现

- 桌面端默认保存到 `%LOCALAPPDATA%/MiniCodex`，可用 `--data-dir` 指定本地目录。SQLite WAL + FULL 同步保存对话名称、完整消息、Turn 状态、展示事件和统计；同一数据目录用进程锁防止双开。
- 重启展示并恢复会话；工作区不存在时保留列表，打开时明确报错。重启不会自动运行模型或工具，也不会恢复审批授权。
- 运行中异常退出，补齐悬空回执并记录 `state=unknown`，任务标记“结果未知”。仅当用户发起新任务才继续；先检查现场，不自动重放补丁或命令。正常停止/关闭保存 cancelled，不混同于崩溃。
- 每条模型请求前按 UTF-8 字节和消息开销保守估算，计入工具 Schema、工具参数和结果；支持上下文、回答预留及整轮累计输入预算。默认 32000 / 4096 / 512000，可在设置中修改。没有针对任意模型的精确 tokenizer，不是实际账单 Token 或费用。
- 超限时生成确定性的结构化提取摘要，包含目标、已改文件、失败证据、历史回答、下一步检查和未验证事项；保留最近完整调用组及当前任务。原始消息不被摘要覆盖。不额外调用付费模型；摘要有损，必要时重新读取原文件或工具归档。
- 工具结果超过 12000 UTF-8 字节则裁剪展示/模型回执，保留首尾内容和归档 ID。完整脱敏结果原子保存并校验 SHA-256，通过 `read_observation` 分页回读；归档仅限当前会话。单项最多 16 MiB、单次运行去重预算 64 MiB，超限明确说明无法完整归档。
- 加载工作区根目录 AGENTS.md；读取子目录文件后，后续步骤加载其祖先链约定。深层约定优先于祖先约定，多个分支按路径限定范围。每个文件最多 16 KiB、合计 32 KiB，模型视图进一步受上下文预算限制；不加载工作区外约定，不将文件内容提升为系统指令或授予工具权限。
- SQLite 是恢复依据；`trace.jsonl` 为追加的事件元数据追踪，关联 thread/turn/step/call/sequence。默认不写 Prompt、正文、argv、环境变量或认证头。JSONL 失败会提示，SQLite 会话仍可恢复；SQLite 写入失败则停止继续执行工具，修复存储后重启。
- GUI 可查看步骤、上下文压缩信息并导出 JSONL。默认只导出事件元数据和统计；勾选“导出包含对话正文”后才包含脱敏正文。辅助命令：`python -m minicodex trace show <thread_id> --data-dir <目录>`，只读查看，不触发恢复或工具执行。

## 验证

155 项核心、GUI、集成、安全及真实文件/进程测试；Ruff 格式/检查、mypy strict 覆盖 47 个源文件。

- 会话重命名、多会话隔离、关窗/新窗口恢复、继续对话和导出。
- 模型等待及审批等待中关闭窗口，恢复为已停止；未获批准的补丁没有写入。
- 实际子进程在原生命令写文件后异常退出，重启为未知结果、历史完整、无重复执行和审批沿用。
- 30 次工具步骤、31 次模型请求，工具原结果超过 1 MB，模型窗口始终受预算约束，压缩后调用/回执保持配对，原件可分页回读。
- 当前任务超预算不丢弃输入、不发起模型调用；累计预算达到上限时明确终止。
- 根/子目录规则优先级、工作区外规则排除、估算包含参数和 Unicode。
- 已知密钥（含 JSON 转义）脱敏；默认追踪和导出不带原始 Prompt。
- 存储故障前阻止补丁执行、JSONL 故障不破坏 SQLite、较新数据版本拒绝打开且保留原数据、只读 CLI 不改变运行中状态。
- v0.4.0 程序包离线/本地 HTTP/M2 原生闭环三项自检全部通过，均检查关闭数据库后重新打开恢复记录；移除 Python PATH 启动通过。

## 边界

SQLite 会保存本机对话正文及项目内容，经过已知 API Key 和常见 `sk-` 密钥脱敏；不是任意秘密识别或加密存储。默认 JSONL 不含正文。模型服务仍只接收用户选择配置下的任务上下文。

模型设置和 Key 仍不跨重启保存；新进程默认离线/只读，需要重新配置服务。Windows 凭据管理与设置迁移是 Task-023，安装/卸载是 Task-024，均未混入本阶段。旧 v0.3.1 只有内存会话，无法从旧进程自动迁移历史。

恢复不等于接着执行旧工具；上次命令即使清理也可能已写入文件，需检查现场。原生执行无 OS 沙箱。结构化摘要可能省略细节，估算不能保证精确匹配服务端 tokenizer。官方 API、Docker、干净 Windows 和真实模型修复能力不因这些本地测试而宣称已验收。

证据见 `artifacts/m3-validation.json`、程序包自检 JSON 和预览图。

# v0.5.2 · 对话列表菜单

2026-10-15。左侧底部移除“重命名对话”“导出任务记录”和“导出包含对话正文”控件，保留新建对话。每条对话右侧常驻三个点按钮，菜单只有“重命名”和“删除对话”；长标题截断显示，鼠标提示保留完整标题及项目路径。点击标题继续对话，列表内 F2 仍可重命名。前三档权限与输入框布局沿用 v0.5.1。

菜单始终针对它所在的那条对话；操作未选中的对话不会切换当前对话，也不清空当前草稿。删除前确认，默认取消；运行中禁用对话操作。删除当前对话后切换到其他可用对话；无可用对话时显示空状态，保留项目入口，可新建对话。

删除由 Facade → ThreadManager → 存储层处理。SQLite 在同一事务删除指定会话的事件、轮次和消息记录，提交成功后才从内存移除；数据库中途失败会回滚。内存后端同样支持删除。重启不会恢复被删会话，其他对话和项目文件不变。

删除不是安全擦除：已有元数据审计追踪、独立工具归档、手动导出或备份不会被自动清除，SQLite 空闲页也没有进行物理擦除。Ctrl+Shift+E 保留当前对话元数据导出；正文导出仅保留在显式调用的应用接口中。

新增 7 项回归，完整测试共 197 项通过；Ruff 检查/格式覆盖 85 个 Python 文件，mypy strict 覆盖 54 个源文件。覆盖非当前行重命名/删除、当前和最后对话删除、重启不恢复、项目文件保留、取消/故障保留会话、运行中禁止删除、内存/SQLite 行为及数据库部分删除回滚。

交付 `dist/0.5.2/MiniCodex/MiniCodex.exe` 和 `dist/0.5.2/MiniCodex-0.5.2-Setup.exe`。界面预览与验证记录位于 `artifacts/ui-052-preview.png`、`artifacts/ui-052-menu.png`、`artifacts/ui-0.5.2-validation.json`。安装器沿用 M4，未做代码签名；Docker、干净系统和真实多屏的待办边界不变。
